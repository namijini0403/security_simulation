# 0009 설치 부품 0개

## 상황

프로그램을 받는 사람은 개발자가 아닌 교사이고, 두 번째 노트북에서는 저장소를 내려받아 바로 실행해야 한다. 발표장에는 인터넷이 없을 수 있다. 필요한 것은 HTTP 서버 몇 개, JSON, 쿠키, 화면 파일 내보내기, 검사다.

## 결정

`package.json`에 의존 부품을 하나도 넣지 않는다. Node.js 22 이상에 들어 있는 것만 쓴다(`node:http`, 내장 `fetch`, `node:test`). 화면은 순수 HTML/CSS/JavaScript다.

## 버린 대안

- **웹 프레임워크와 검사 도구 설치**: 경로 처리, 쿠키, 정적 파일을 직접 쓰지 않아도 된다. 그러나 `npm install`이 필요해지고, 그것은 인터넷과 명령어 입력을 요구한다. 내려받은 ZIP을 풀고 더블클릭하면 실행된다는 흐름이 깨지고, 발표 중 명령어를 치지 않는다는 조건과도 부딪힌다.
- **화면에 프레임워크나 바깥 글꼴 쓰기**: 인터넷 없이 동작해야 한다는 조건과 부딪힌다.

## 결과

- 본문 읽기(크기 제한), 화면 파일 내보내기(폴더 밖으로 나가지 못하게), 쿠키 읽고 쓰기, 경로 맞추기를 직접 만들었다. 이 코드들이 `src/shared/http.js`에 모여 있고, 여기에 결함이 생기면 "허술함은 권한 확인 하나뿐"이라는 선이 깨진다(예: 화면 파일 요청으로 폴더 밖의 파일이 나가는 것). 그래서 이 도구들의 검사가 두껍다.
- Node.js 최소 버전이 22다. 내장 `fetch`, `AbortSignal.any`, `Response`의 `getSetCookie`, `node:test`의 경로 묶음 실행 등을 전제로 한다. 더 낮은 버전을 받아들이려면 이것들을 대신할 코드가 필요하다.
- 편의를 위해 부품을 하나만 더하는 것도 할 수 없다. 더하는 순간 설치 단계가 생긴다.
- 화면은 서버 상태를 주기적으로 읽어 직접 그린다. 실시간 통신 부품이 없으므로 갱신은 1초 주기다.
