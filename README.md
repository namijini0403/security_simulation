# LOCAL ≠ SAFE 시연 앱

초등학교 교직원 세미나에서 발표자 한 사람이 노트북으로 25~30분 동안 진행하는 **교육용 시연 프로그램**입니다.

- **1부(약 20분)** — “한 선생님이 AI의 도움을 받아 만든 성적 관리 앱”에서 학생 기록이 얼마나 쉽게 새어 나가는지를 하나의 이야기로 보여 줍니다.
- **2부(약 7분)** — AI가 학생의 감정일지를 그럴듯하게 해석했을 때 교사의 판단이 어떻게 끌려가는지 함께 확인합니다.

화면에 나오는 성공과 거절은 미리 만들어 둔 그림이 아니라, 그 순간 프로그램이 실제로 주고받은 결과입니다.
선생님들은 화면만 보고, 조작은 발표자만 합니다.

> 화면의 학생, 보호자, 성적, 연락처는 모두 프로그램이 지어낸 가짜입니다.
> **실제 학생·학부모의 정보를 어떤 방법으로도 넣지 마세요.** 프로그램을 고쳐서 넣는 것도 안 됩니다.
>
> **2. 인터넷에 올리지 마세요.**
> 이 프로그램을 인터넷이나 누구나 들어올 수 있는 주소에 올려 두면 안 됩니다.
> 내 컴퓨터에서 잠깐 실행해 보여 주는 용도로만 씁니다.
>
> **3. 다른 기기 접속은 전용 실습용 연결에서만 켜세요.**
> 화면의 '다른 기기 접속'은 발표자의 휴대폰 핫스팟처럼 **두 노트북만 연결된 전용 연결**에서만 켭니다.
> **학교 와이파이, 공용 와이파이에서는 절대 켜지 마세요.**
>
> **4. 1번 앱은 일부러 허술하게 만든 앱입니다.**

>
> **5. 2번 앱도 완성된 본보기가 아닙니다.**
> 2번 앱은 특정 접근통제 원리 하나를 보여 주는 비교용 예제입니다.
> 실제 학교 서비스에 그대로 쓸 수 있는 인증 체계가 아닙니다.

## 필요한 것

- **Node.js 22 이상** — 이 프로그램을 실행해 주는 무료 프로그램입니다. 이것 하나만 설치하면 됩니다. 그 밖에 따로 설치할 부품은 없습니다.
- **Chrome 또는 Edge** 브라우저
- (선택) **두 번째 노트북** — “다른 기기에서 열린다”는 장면을 실제로 보여 주려면 필요합니다. 없으면 한 대로도 진행할 수 있습니다.
- (두 대로 할 때) 두 노트북만 연결할 **전용 연결** — 휴대폰 핫스팟, 또는 학교 통신망에 연결하지 않은 별도 공유기

인터넷 연결은 설치할 때(Node.js와 이 프로그램을 내려받을 때)만 필요합니다. 프로그램 자체는 인터넷 없이 작동합니다.

## 1단계. Node.js 설치하기

이미 Node.js 22 이상이 있으면 건너뛰어도 됩니다. 있는지 모르겠으면 그냥 2단계, 3단계로 가서 실행해 보세요.
없거나 오래된 버전이면 실행 파일이 한국어로 알려 줍니다.

### Windows

1. 브라우저에서 Node.js 공식 사이트 <https://nodejs.org> 를 엽니다.
2. **LTS**라고 적힌 Windows 설치 파일을 내려받습니다.
3. 내려받은 파일을 더블클릭해 설치합니다. 설정은 바꾸지 않고 계속 넘기면 됩니다.
4. 설치가 끝나면 열려 있던 검은 창(명령 프롬프트)이 있다면 모두 닫습니다.

### macOS

1. 브라우저에서 Node.js 공식 사이트 <https://nodejs.org> 를 엽니다.
2. **LTS**라고 적힌 macOS 설치 파일(`.pkg`)을 내려받습니다.
3. 내려받은 파일을 더블클릭해 설치합니다. 설정은 바꾸지 않고 계속 넘기면 됩니다.

### 설치가 되었는지 확인하고 싶다면

- Windows: 시작 메뉴에서 “명령 프롬프트”를 열고 `node -v` 를 입력한 뒤 Enter를 누릅니다.
- macOS: “터미널”을 열고 `node -v` 를 입력한 뒤 return을 누릅니다.

`v22.…` 또는 그보다 큰 숫자가 나오면 됩니다.

## 2단계. 프로그램 내려받기

1. 브라우저에서 <https://github.com/namijini0403/security_simulation> 을 엽니다.
2. 초록색 **Code** 단추를 누르고 **Download ZIP**을 고릅니다.
3. 내려받은 압축 파일을 **모두 풉니다.** (Windows: 파일을 오른쪽 단추로 눌러 “압축 풀기”. macOS: 더블클릭)
4. 풀린 폴더를 바탕 화면이나 문서 폴더처럼 찾기 쉬운 곳에 둡니다.

> 압축 파일 안에서 바로 실행 파일을 더블클릭하면 실행되지 않습니다. 반드시 먼저 압축을 풀어 주세요.

git을 쓰는 분은 이렇게 받아도 됩니다.

```
git clone https://github.com/namijini0403/security_simulation.git
```

### 두 번째 노트북에도 똑같이

두 대로 진행할 때는 **두 번째 노트북에도 1단계와 2단계를 똑같이** 합니다.
두 번째 노트북에서는 **받는 쪽 프로그램**만 실행합니다.
인터넷이 필요한 설치와 내려받기는 발표 전에 미리 끝내 두세요.

## 3단계. 실행하기

### 더블클릭으로 실행 (권장)

| 무엇을 | Windows | macOS |
|---|---|---|
| 시연 프로그램 (첫 번째 노트북) | `시연 시작.bat` 더블클릭 | `시연 시작.command` 더블클릭 |
| 받는 쪽 프로그램 (두 번째 노트북, 한 대로 할 때는 같은 노트북) | `받는 쪽 시작.bat` 더블클릭 | `받는 쪽 시작.command` 더블클릭 |

더블클릭하면 글자가 나오는 창이 하나 열리고, 곧 브라우저에 첫 화면이 열립니다.
**글자가 나오는 창은 프로그램 그 자체입니다. 발표가 끝날 때까지 닫지 마세요.**

실행 파일이 하는 일은 Node.js를 찾아 프로그램을 실행하는 것뿐입니다.
네트워크나 방화벽 설정을 바꾸지 않고, 관리자 권한을 요청하지 않으며, 아무것도 내려받거나 설치하지 않습니다.

### 명령어로 실행 (익숙한 분)

프로그램 폴더에서 명령 프롬프트(또는 터미널)를 열고 입력합니다.

| 명령 | 하는 일 |
|---|---|
| `npm run demo` | 시연 프로그램 실행 |
| `npm run receiver` | 받는 쪽 프로그램 실행 |
| `npm test` | 자동 검사 실행 |

> **`npm test`를 돌릴 때 주의**: 자동 검사는 다른 기기 접속 기능을 확인하느라 이 컴퓨터의 내부 주소에 임시로 문을 몇 초씩 열었다 닫습니다.
> 학교 와이파이나 공용 와이파이에 연결된 상태에서는 돌리지 마세요. 와이파이를 끄거나 전용 연결에서 돌리면 됩니다.
> 발표만 하실 분은 `npm test`를 돌릴 필요가 없습니다.

### 끝내기

글자가 나오는 창을 닫으면 프로그램이 끝납니다. 그 창에서 Ctrl+C(macOS는 control+C)를 눌러도 됩니다.
Windows에서 Ctrl+C를 누른 뒤 계속할지 묻는 문장(Y/N)이 나오면 Y를 누르거나 그냥 창을 닫으세요.

프로그램을 끄면 화면의 모든 데이터가 사라지고(파일로 저장하지 않습니다), 다른 기기 접속도 함께 닫힙니다.

## 네 개의 주소

실행하면 아래 주소가 생깁니다. 모두 프로그램을 실행한 그 컴퓨터 안의 주소입니다.

| 화면 | 주소 | 어느 프로그램 | 다른 기기에서 |
|---|---|---|---|
| 진행 화면 (발표자 화면, 프로젝터에 나가는 화면) | `http://127.0.0.1:4170` | 시연 | **어떤 경우에도 열리지 않습니다** |
| 1번 앱 | `http://127.0.0.1:4173` | 시연 | 진행 화면에서 '다른 기기 접속'을 켰을 때만 |
| 2번 앱 | `http://127.0.0.1:4174` | 시연 | 진행 화면에서 '다른 기기 접속'을 켰을 때만 |
| 받는 쪽 | `http://127.0.0.1:4180` | 받는 쪽 | 받는 쪽 화면에서 '다른 기기 접속'을 켰을 때만 |

- 1번 앱과 2번 앱에는 각각 '옆 사람 화면'이 있습니다. 주소 끝에 `/neighbor` 를 붙이면 열립니다. (예: `http://127.0.0.1:4173/neighbor`)
  진행 화면의 '새 창으로 열기 (이 PC)'에 있는 단추로도 열 수 있습니다.
- 실행 직후에는 **모든 화면이 그 컴퓨터 안에서만 열립니다.** 다른 기기 접속은 화면에서 경고를 읽고 '확인'을 눌렀을 때만 켜지고, 30분 뒤 자동으로 꺼집니다.

### 실습용 계정

성적 관리 앱의 로그인 화면에서 쓰는 고정 계정입니다. 교육용 계정이며 실제 인증 체계를 대신하지 않습니다.

| 누구 | 로그인 ID | 비밀번호 |
|---|---|---|
| 담임 | `teacher` | `teacher1234` |
| 학부모 (20명) | `parent01` ~ `parent20` | `demo1234` |

## 문제 해결

### “Node.js를 찾지 못했습니다”라고 나옵니다

Node.js가 설치되어 있지 않습니다. 위의 1단계대로 설치한 뒤, 열려 있던 창을 닫고 실행 파일을 다시 더블클릭하세요.
방금 설치했는데도 같은 문장이 나오면 컴퓨터를 한 번 다시 켠 뒤 해 보세요.

### “Node.js가 너무 오래된 버전입니다” 또는 “Node.js 22 이상에서 실행됩니다”라고 나옵니다

22보다 낮은 버전이 설치되어 있습니다. 1단계대로 **LTS** 설치 파일을 받아 그 위에 다시 설치하면 됩니다.

### “○○번 포트를 이미 다른 프로그램이 쓰고 있어서 시작할 수 없습니다”라고 나옵니다

대부분 **같은 프로그램을 이미 한 번 실행해 둔 것**입니다. 먼저 실행해 둔 글자 창을 찾아 닫은 뒤 다시 실행하세요.
찾을 수 없으면 컴퓨터를 다시 켜면 해결됩니다.

### “프로그램 파일을 찾지 못했습니다”라고 나옵니다

압축을 풀지 않고 실행했거나, 실행 파일만 다른 곳으로 옮긴 경우입니다. 압축을 모두 푼 폴더 안에서 실행하세요.

### 브라우저가 저절로 열리지 않습니다

브라우저(Chrome 또는 Edge)를 직접 열고 주소창에 입력하세요.

- 시연 프로그램: `http://127.0.0.1:4170`
- 받는 쪽 프로그램: `http://127.0.0.1:4180`

### 기본 브라우저가 Chrome이나 Edge가 아닙니다

열린 화면의 주소를 복사해 Chrome 또는 Edge 주소창에 붙여 넣으면 됩니다.

### Windows: 파란색 “Windows의 PC 보호” 창이 나옵니다

인터넷에서 내려받은 실행 파일을 처음 열 때 나올 수 있습니다. 이 저장소에서 직접 내려받은 파일이 맞다면 “추가 정보”를 누른 뒤 “실행”을 누릅니다.

### Windows: 방화벽 알림 창이 나옵니다

보통 '다른 기기 접속'을 처음 켤 때 나옵니다. 전용 실습용 연결에서 켠 것이 맞다면 **개인 네트워크에만** 허용하세요.
자세한 내용과, 예전에 막아 버렸을 때의 조치는 [`NETWORK_GUIDE.md`](NETWORK_GUIDE.md)에 있습니다.
'다른 기기 접속'을 켜지 않고 한 대로만 진행한다면 허용하지 않아도 됩니다.

### macOS: “확인되지 않은 개발자” 또는 “열 수 없습니다”라고 나옵니다

인터넷에서 내려받은 `.command` 파일을 처음 열 때 나올 수 있습니다.

1. 파일을 control 키를 누른 채 클릭(또는 오른쪽 클릭)하고 “열기”를 고릅니다. 다시 묻는 창에서 “열기”를 누릅니다.
2. 그래도 안 되면 “시스템 설정 → 개인정보 보호 및 보안”을 열어 아래쪽에 나온 이 파일의 “그래도 열기”를 누릅니다.

### macOS: “권한이 없어서 열 수 없습니다”라고 나옵니다

실행 권한이 빠진 경우입니다. “터미널”을 열고 아래 두 줄을 차례로 입력합니다. 첫 줄의 `cd ` 뒤에는 프로그램 폴더를 터미널 창으로 끌어다 놓으면 폴더 위치가 자동으로 입력됩니다.

```
cd 프로그램_폴더_위치
chmod +x "시연 시작.command" "받는 쪽 시작.command"
```

그래도 더블클릭으로 열리지 않으면 같은 터미널 창에서 `npm run demo` (받는 쪽은 `npm run receiver`)를 입력해 실행할 수 있습니다.

### 진행 화면에 '연결이 끊겼습니다 — 시연 프로그램이 켜져 있는지 확인하세요'가 나옵니다

시연 프로그램의 글자 창이 닫힌 것입니다. `시연 시작` 파일을 다시 더블클릭하세요. 데이터는 처음 상태로 돌아갑니다.

## 확인한 것과 확인하지 못한 것

이 문서를 쓰는 시점에 만든 사람이 확인한 범위입니다. 처음 써 보실 때 참고하세요.

- **확인함**: Windows 11에서 `시연 시작.bat`, `받는 쪽 시작.bat`을 더블클릭과 같은 방식으로 실행해 프로그램이 시작되는 것, 한글 안내문이 깨지지 않는 것, Node.js가 없을 때와 오래된 버전일 때의 안내문.
- **확인하지 못함**: macOS용 `시연 시작.command`, `받는 쪽 시작.command`는 문법 검사와 Windows의 bash에서의 시험 실행만 했고, **실제 Mac에서는 실행해 보지 못했습니다.**
- **확인하지 못함**: **실제 노트북 두 대**를 핫스팟이나 공유기로 연결해 진행하는 것, 그리고 그때 나오는 Windows·macOS 방화벽 알림 창의 모습은 직접 확인하지 못했습니다. 관련 안내는 일반적인 동작을 바탕으로 썼으므로, 발표 전에 반드시 실제 장비로 미리 해 보세요.
